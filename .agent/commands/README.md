# joi · AI 命令索引

本目录面向在 joi 仓库中工作的 AI Agent。所有命令都从仓库根目录执行，Node.js 与 npm 版本要求以 `package.json#engines` 为准，实际脚本定义以 `package.json#scripts` 为准。

| 任务 | 命令文件 | 使用场景 |
|------|----------|----------|
| 开发运行 | [开发运行](dev.md) | 安装依赖、启动开发态或本地生产形态 |
| 验证 | [验证](verify.md) | 定向测试、固定质量门禁和平台额外验证 |
| 国际化 | [语言维护](i18n.md) | 增删语言、文案、覆盖率和生成资源检查 |
| 打包 | [打包](package.md) | 桌面端、Android 与远程中继产物 |
| 清理 | [清理](clean.md) | 删除仓库内可重建的构建和测试产物 |

## Agent 使用约束

- 执行命令前先读取对应文件，不根据记忆猜测脚本名或平台能力。
- 测试必须使用临时 SQLite、`userData` 和凭据替身，不读取真实用户数据。
- 没有实际执行的验证不得标记为通过；平台、签名或外部设备限制必须明确报告。
- 不记录或输出 token、cookie、CSRF、消息正文、persona、memory、A2A payload 或本机绝对路径。
- 清理和打包可能影响可重建产物；执行前遵守对应文件中的范围限制。

旧入口 [`.agent/commands.md`](../commands.md) 保留为兼容摘要。
