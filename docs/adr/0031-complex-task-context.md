# ADR 0031：复杂任务的相关证据、综合快照与历史软预算

- 状态：accepted
- 日期：2026-10-19
- 关联：ADR 0022、0025、0026、0027、0028；AC-43/48/53/67

## 决策

执行上下文分为必要要求和当前指令、可选相关证据、可检索历史。有效要求、权限、验收不进入可选证据裁剪。保留结果正文、验收、历史会话及目标结论，不停止、重启或重放当前运行；后续派发、下一轮综合及显式恢复在自然边界采用新策略。

### 证据

`WorkBrief.evidenceResultIds` 为可选显式引用；派发和恢复同时校验结果存在、工作台、原始目标，提交事务再次校验。选择采用确定性顺序：显式引用、依赖链、同目标既有结论与未解决缺口、其他近期结果；相同结果只出现一次。失败、迟到、非权威及未验收结果保留身份，不能作为已通过验收的成功证据。

可选证据默认 24,000 字符，候选上限 40,000/60,000 字符；按实际序列化容量衡量。省略正文时保留引用、总数、省略标记和读取入口。主 joi 的 `work_read_evidence` 提供目标限定索引和历史结论，`work_read_result` 提供完整正文，默认 8,000 字符分页；Pi 搭档通过执行快照闭包提供相同读取能力，不能自行选择另一目标。

Claude/Codex 使用现有输入准备路径，在工作区之外暂存只读索引和正文。快照 ID 加内容摘要决定稳定目录，临时目录完成后原子发布，重试核验完整内容并复用。辅助输入不进入工作区产物扫描或机械验收。没有读取能力或准备失败时使用内联回退并记录计数；A2A 消息保持自包含，不发送本机文件读取入口，也不要求远端协议升级。

### 综合

持久用户消息只保存综合指令和结果/需求版本，不存累计清单或证据正文。`loadInput` 为历史综合消息提供紧凑投影，不批量改写原始记录。每请求背景只带上轮结论、本轮新增或变化的结果身份与摘要、覆盖缺口数量和分页入口；首次综合直接通过索引读取所需证据。长结论保留首尾和版本身份，完整结论仍可分页读取。

会话命名空间为 `joi_synthesis_snapshot_v1:{workbenchId}:{goalId}:r{resultRevision}:q{requirementsRevision}`，隔离旧累计清单会话以及新结果/新需求。同一双版本在进程重启后保持相同基础身份。背景复用既有请求级机制，不进入持久用户消息、会话 transcript 或压缩摘要。

迁移 076 增加目标结论历史，以目标/结果版本/需求版本为键；回填已有当前结论。发布结论仍经过已有取消、活动 Work、当前 synthetic input、结果/需求双版本门禁；通过门禁后在同一事务保存历史。优化不放宽文字结项、结项纠正、失败 park、用户恢复或完成标准。

### 历史与诊断

主 joi/Pi 可控历史默认在 128,000 序列化字符触发摘要，目标 64,000，同时服从更小的实际模型容量。保留当前任务、必要要求、最新完整工具交换、结论、引用和未决事项。摘要失败不覆盖旧检查点；请求上的未覆盖部分明确标记，私有历史仍可通过 `context_read_history` 回读。原生 SDK 和远端继续管理各自内部历史，本次只管理可观察的发送侧证据。

诊断只对已定义事件中指定数值字段精确放行，包括 `compactedMessages`、`tokensBefore`、`omittedMessages`；字符串、嵌套伪装和其他事件不继承豁免。正文、凭据、路径继续拒绝。统计上下文规模、证据数量、预算回退、压缩前后大小及摘要耗时；模型请求、工具和工作区等待沿各自诊断/usage 维度观察。输入 token 已含缓存，不重复累加缓存 token。没有固定供应商响应时间验收门槛。

## 验证

使用临时 SQLite、虚拟模型、SDK 请求捕获和隔离原生配置；163 结果、多层依赖和 7 轮综合覆盖不自动注入未选正文、首尾保留、中段证据分页可达、同版本重建、验收身份及作用域。回归覆盖需求变化、新结果、取消、迟到、旧会话、摘要失败、无读取工具、输入准备重试和内联回退。固定门禁与实际结果见验证报告；不以供应商延迟作为确定性测试断言。
