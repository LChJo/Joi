# 复杂任务上下文优化验证

日期：2026-10-19。验收依据：AC-43/48/53/67、ADR 0031。

## 输入规模与重复量

- 普通选择夹具含 163 结果，初始可选证据不超过 24,000 序列化字符；无关正文不自动注入，索引保留全部身份。
- 实际执行读取夹具以显式中段结果和两层依赖触发 40,000/60,000 字符扩档，普通近期结果不触发扩容。JSON 转义放大单独回归；巨型必需引用元数据超出 60K 时保守回退并计数。
- 163 结果的 7 轮综合没有累计结果清单进入持久用户消息，每轮指令小于 6,000 字符；背景不含结果正文。原始正文仍全部保存在 SQLite，索引和正文按 8,000 字符分页可达。
- 同结果/需求版本进程重建保持基础会话身份；新结果或需求版本进入独立命名空间。旧累计清单只在加载时投影为紧凑指令，原始存储不被批量改写。
- 超长结论和显式结果保留首尾、身份、遗漏标记及完整读取入口。未验收、失败、迟到及非权威结果不能升级成成功证据；本轮新增结果同时使同 Work 旧引用进入核对范围。
- SQLite 正文读取仍使用有界 `substr`，游标跟随 SQLite codepoint 坐标；传输页不超过 8,000 个 JS 字符且不拆 Unicode 代理对。9,000 个 emoji 和 ASCII/emoji 边界夹具可逐页重组完整尾部。原生只读页文件也保留 Unicode 完整性。

最后一项只比较重复清单和新指令的规模，不把必要要求、背景、历史或按需读取算作零输入，也不代表真实供应商 token 或速度收益。

## 引擎与故障回归

- 主 joi、Pi 和旧 Pi 适配入口均有证据分页工具；主控长单轮工具链在下次模型请求前可以生成检查点。
- 128K 字符触发、64K 目标服从模型容量；摘要失败保留旧检查点，未覆盖历史明确标记。主控源历史私有持久归档；Pi 常驻的新 Work 从本轮边界限定历史工具，同 Work 继续沿用。旧无 Work 标签的冷恢复历史只能从最新用户任务锚回读。
- Claude/Codex 适配器请求携带只读任务索引，必要要求不受证据裁剪。完整原文与 8K 页文件均在工作区外，机械验收和交付物扫描不会认领；相同快照及内容重试复用相同输入目录。
- 原生 CLI 使用隔离配置和回环供应商替身：开启 `JOI_NATIVE_WRITE_TESTS=1` 的完整套件 5 通过、2 按既有 `JOI_NATIVE_TOOL_SMOKE=1` 开关跳过（Codex 实际写工具和外部证据 shell）。Claude 实际 Read 已成功读取工作区外索引和正文。显式开启 Codex 证据工具冒烟时，控制步骤读取普通 `cwd/input.txt` 即执行失败，尚未访问外部路径；本机原生 shell 执行环境受限，不能声称 Codex 实际外部文件读取已通过，需在支持该原生工具的环境复验。生产 sandbox、权限和执行时限未放宽。
- 没有 Read、输入准备失败和 A2A 采用自包含内联证据，显式/依赖全文保留；A2A 不引用本机路径，不要求远端增加工具。
- 原有取消、活动 Work、结果/需求双版本、综合纠正、文字结项、失败 park、显式恢复及 outbox 幂等回归保持覆盖。

## 遥测与耗时

诊断精确放行指定事件的数值统计，凭据、正文、路径和嵌套伪装继续拒绝。请求记录背景/要求/历史规模与预算回退；摘要记录前后规模和耗时；模型、工具及 READ/WRITE 工作区排队分别记录耗时。输入 token 已含缓存，缓存不重复累加。

自动化检验事件字段、归属及非负耗时，不以模拟供应商耗时代表真实收益，也不设供应商响应时间门槛。真实任务只在自然边界观察；本次没有停止、重启、重放或修改正在执行的飞书任务。后续实际日志可按 engine/purpose 和请求规模分箱比较耗时分布，不能把输入下降直接等同于供应商延迟下降。
