## 1. 通过标准

以下项目全部通过，才可以移除旧浏览器远程回退：

- 新设备使用十分钟、一次有效的二维码成功绑定；同一二维码不能绑定第二次。
- 手机和电脑处于同一 Wi-Fi 时，App 最终显示“直连”。
- 手机切换到 5G、无法局域网直连时，App 自动恢复并显示“中继”，无需修改服务器地址或重新扫码。
- 至少两台 Android 设备可以同时绑定同一 Joi，并独立保持连接。
- 每台手机都能查看 Joi 首页任务卡并发送文字；各端刷新后内容一致，重复提交不产生重复卡片。
- 桌面端撤销一台手机后，该手机不能继续访问，其他已绑定手机不受影响。
- Joi 和手机 App 重启后，未撤销设备可以使用安全存储中的凭据自动恢复连接。

## 2. 准备

需要以下产物和设备：

- Windows 桌面端：`release-joi/win-unpacked/joi.exe`
- Android 安装包：`release-joi-mobile/joi-android-0.1.0-arm64.apk`
- 一台 Windows 电脑和至少一台 arm64 Android 手机；多设备验收需要两台手机或两个独立 Android App 实例。
- 可用的 Wi-Fi 和手机 5G 网络。
- 默认中继：`https://remote.joilab.top`

开始前：

1. 从 Windows 托盘彻底退出正在运行的旧 Joi，不要只关闭窗口。
2. 启动上述新版 `joi.exe`，完成必要的首次设置，确认首页可以正常显示。
3. 在 Android 安装 APK，并允许扫码所需的相机权限和网络权限。
4. 如果 App 中存在旧绑定，先在桌面 Joi 移除对应设备，再重新扫码。旧绑定票据可能仍携带旧中继地址。
5. 不要把二维码、`joi://pair` 连接码、设备凭据或任务正文放入截图、日志和问题报告。

## 3. 启用默认中继

1. 在桌面 Joi 打开设置，找到“Joi 手机”。
2. 确认“iroh 中继地址”为 `https://remote.joilab.top`。
3. 勾选“允许已绑定的 Joi Android App 连接”。
4. 点击“保存远程设置”。
5. 等待状态从“正在建立安全链路”自动变为“手机链路已就绪”，并看到提示“Joi 手机链路已就绪”。
6. 确认“生成绑定二维码”按钮已经可以点击。

通过条件：不需要手动刷新页面，状态能够自动变为“手机链路已就绪”。如果需要验证手动配置能力，可临时填入另一个受信任的 HTTPS iroh relay 并保存；完成后必须改回默认地址。

## 4. 扫码绑定第一台手机

1. 点击“生成绑定二维码”。二维码十分钟后失效，成功绑定后立即失效。
2. 在手机 App 点击“扫描二维码绑定 Joi”，扫描桌面二维码。
3. 如果相机扫码不可用，可点击“输入连接码”，粘贴完整的 `joi://pair` 链接；不要通过不受信任的聊天工具传输连接码。
4. 等待 App 进入主界面，确认能看到连接状态、任务卡区域和文字输入框。
5. 回到桌面“Joi 手机”，确认设备列表出现该手机，并记录了最近连接时间。
6. 尝试再次使用同一二维码绑定另一个 App 实例。

通过条件：第一台手机绑定成功；同一二维码第二次使用被拒绝；桌面设备列表只新增预期设备。

## 5. 同一 Wi-Fi 直连

1. 让电脑和手机连接同一个 Wi-Fi；关闭手机 VPN、代理和移动网络加速功能。
2. 保持桌面 Joi 运行，将手机 App 切到前台。
3. 等待最多 30 秒，观察 App 顶部连接状态。
4. 在手机输入一条唯一文字，例如 `直连端测-日期-时间`，并提交。
5. 确认桌面首页出现对应内容，手机任务卡随后刷新且没有重复项。

通过条件：App 显示“直连”，文字提交和任务卡刷新正常。若同一 Wi-Fi 始终显示“中继”，记录路由器是否启用了 AP 隔离、访客网络或设备互访限制，该项暂不算通过。

## 6. 5G 中继与网络切换

1. 保持桌面 Joi 运行，不修改中继地址，也不重新扫码。
2. 在手机关闭 Wi-Fi，确认实际使用 5G。
3. App 短暂显示“重连中”属于正常现象；等待最多 60 秒。
4. 确认 App 恢复到“中继”。
5. 查看已有任务卡，并提交一条唯一文字，例如 `5G中继端测-日期-时间`。
6. 确认桌面收到内容，手机任务卡刷新正常。
7. 重新打开 Wi-Fi，观察连接能够继续工作；在网络条件允许时应恢复“直连”。

通过条件：Wi-Fi 与 5G 切换期间无需重绑；5G 下最终显示“中继”，任务读取和文字提交均成功。

## 7. 两台手机并发

每个二维码只能使用一次，因此第二台手机必须生成新的二维码。

1. 保持第一台手机已连接。
2. 桌面再次点击“生成绑定二维码”，使用第二台手机扫码。
3. 确认桌面设备列表同时显示两台手机。
4. 两台手机分别提交不同的唯一文字。
5. 等待任务卡自动刷新，确认桌面和两台手机最终看到一致内容。
6. 一台手机保持 Wi-Fi，另一台切换到 5G，确认二者可以分别显示“直连”和“中继”并同时操作。

通过条件：两个设备会话互不挤占、互不串线，任一设备提交内容都不会让另一设备掉线或产生重复卡片。

## 8. 重启恢复与逐台撤销

1. 完全退出并重新打开第一台手机 App，确认无需扫码即可恢复连接。
2. 从托盘彻底退出并重新启动桌面 Joi，确认两台未撤销手机均可自动恢复。
3. 在桌面“Joi 手机”设备列表中移除第一台手机。
4. 确认第一台手机不能再读取任务卡或发送文字。
5. 确认第二台手机仍保持连接，并能正常读取和提交。
6. 第一台手机如需恢复，必须使用新二维码重新绑定。

通过条件：重启不丢失合法绑定；撤销只影响目标设备，而且被撤销凭据不能重新连接。

## 10. 失败判定与回退

出现以下任一情况时，保留旧浏览器远程回退，不执行旧方案清理：

- 同一 Wi-Fi 无法建立直连，且已排除 AP 隔离和 VPN。
- 5G 下超过 60 秒仍为“离线”或持续“重连中”。
- 网络切换后必须重新扫码才能恢复。
- 第二台手机连接会挤掉第一台手机。
- 撤销一台设备影响其他设备，或被撤销设备仍能继续访问。
- 任务卡、文字提交出现串设备、重复、丢失或权限越界。

端测失败不需要修改 ECS 或更换域名。先保留现场状态和安全诊断信息，再根据失败步骤定位桌面、Android、局域网发现或 iroh 中继链路。
