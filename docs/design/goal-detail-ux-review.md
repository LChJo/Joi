# 目标详情：鼠标浮层与路线概览 UX 评审

## 用户问题与设计参与

独立交互设计评审师先审计目标详情组件、抽屉布局和样式，再由实现者落地。截图中标题浮层固定在标题左下，长地图即使逐层收起仍占据大量高度。目标是让全文操作贴近触发位置，让最终结果和执行内容保持容易到达。

沿用既有绿灰配色、Phosphor 图标、按钮和焦点样式，不增加依赖，不改变地图事实或后端契约。验收映射 AC-37、AC-44、AC-48。

## 标题交互

- 悬停全文以指针加 12px 为锚，在标题内随鼠标更新；进入正文框后冻结以便滚动、选取，离开两者 180ms 后关闭。
- 点击标题固定全文，供触屏阅读。键盘聚焦锚定标题底边；Shift+F10 或菜单键打开复制菜单并聚焦复制项。
- 右键菜单固定在触发坐标，不追逐鼠标；与全文预览互斥。靠近右侧、底部时翻转，再约束在视口内，保留 12px 边距。
- 全文最大宽 680px，窄窗口宽度减去 24px，高度有界。框内滚动保留浮层；外部滚动、窗口尺寸变化或外部点击关闭。
- Escape 先关浮层并恢复标题焦点，再按才退出目标详情。复制成功收起并反馈；失败保留可选全文，不复制首页的缩略文本。

## 两级信息结构

```text
目标路线图                           推进中／地图已收官
目的地：最多两行……
167 条路径 · 32 项决策 · 1 项雾区
当前第 32 层                         展开路线图 ▾

最终结果／执行内容
```

概览不列出每个历史层，不基于一页数据推算全局成功率。总数来自 pathCount、decisionCount、fogCount；当前层来自 currentLayer。没有路径时展示空态，不显示虚构的第 0 层。

```text
当前第 32 层                         收起路线图 ▴
────────────────────────────────────────────────
路径 167            决策 32             雾区 1
┌ 有界滚动区域 ─────────────────────────────────┐
│ 完整目的地                                    │
│ 已加载 50 / 共 167 项                          │
│ 第 32 层（最新层）                             │
│   路径节点 → 选中节点的说明、决策与晋升关系     │
│ 第 31 层……                                    │
└───────────────────────────────────────────────┘
加载更多路径、决策与雾区／失败重试
```

详情在同一卡片内展开，避免嵌套模态框。桌面滚动区域最多 480px 且不超过 60dvh，640px 以下最多 50dvh。按路径、决策、雾区分区查看，避免所有决策堆在历史层之后。最新层优先且默认打开；历史层按需展开，同层路径并列、窄屏单列。路径说明紧邻选中层。层级线只表示推进顺序，不推测依赖。

收起重开保留分区、展开层、选中路径、已加载页与各分区独立的滚动位置；首次进入一个分区从顶部开始。点击路径后将路径说明带入可见区。轮询不能强制打开概览；切换目标才重置。雾区晋升跳到已加载路径，展开对应层、切回路径分区并定位；目标路径尚未加载时保留加载入口与说明。正文拖选从框内开始后固定浮层，拖出边缘也不因离开计时而消失。

## 加载、失败与事实边界

首次读取显示紧凑占位，不把首页五条路径伪装成完整地图；失败提供重试。已有数据的刷新或分页失败保留最后成功数据和用户选择，在当前阅读层级显示重试。

“已加载”与“共”区分。总数大于零但记录尚未到达时显示“尚未加载”，不能宣称不存在。加载更多只在展开详情内出现。收官不等于所有 Work 成功；路径状态与 Work 状态分别显示。

## 验收与视觉复核

1. 标题不同鼠标位置改变浮层位置，进入全文框冻结，正文可滚动和选取。
2. 菜单固定在触发点、边缘不越界，菜单项真实可点击；键盘、触屏、复制失败与 Escape 可操作。
3. 167 条路径、32 层历史的收起概览高度有界；分页增加数据不增高概览。
4. 展开内容有界、历史/决策/雾区/分页可达；重开、轮询和失败恢复保留交互及内部滚动状态。
5. 480、768px 与桌面下无地图横向溢出，浮层和菜单位于视口内，统计自然换行、焦点清晰。使用合成数据生成真实 Electron 截图并交设计评审复核。

规格见 [交互与页面规格](../02-ux-specification.md)，验收见 [路线图与验收](../07-roadmap-and-acceptance.md)。

## 设计复核结论

独立设计评审完成了方案审计、实现复核和真实 Electron 截图复核。概览在 480、768、1280px 下通过视觉检查；全文预览、触发点菜单及决策详情截图也通过最终复核，无阻塞。分区阅读位置、选中说明可见性、拖选全文跨出边缘这三项细节以失败回归先复现，再实现转绿，并在真实窗口中验证。
