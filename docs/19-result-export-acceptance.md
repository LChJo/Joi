# PC 与 Android 最终结果导出（AC-57 增量）

## 内容与交互

- 阅读快照唯一正文为 `completionSummary`，复制保留原始 Markdown，包括末尾空白；不拼入提问、标题、状态、日志或附件。
- PC 全文弹层固定打开时的正文；Android 从首页结果预览和详情“最终结果 · 查看全文”进入独立页面，调用既有 `goal.get` 分片重组。完整读取前、读取失败或空正文不能导出；已加载快照离线可用。
- 右下角常驻导出图标向上展开复制/PDF/PNG。空白和 Escape/返回优先关闭菜单。底部保留阅读空间，处理中禁用重复操作，失败不显示保存成功。
- 浏览器会话仅提供复制；文件导出、打开和目录定位需要 desktop session，写操作继续校验 Origin/CSRF。
- PC 导出反馈使用紧凑灰绿状态卡：图标与文件数量为主信息，下载 / Joi 为次级位置，同一卡片底部集中放置“打开”和“打开目录”；复制、处理中和错误提示沿用同一容器，屏幕阅读器可读取状态。

## 格式与存储

- 两端使用同一份离线 Noto Sans SC 常规字体和 OFL 许可证。PDF 为 A4 白底、可选文本、分页正文、HTTP(S) 链接；表格和长代码/链接可换行。图片保持占位，不请求外部图片。
- PNG 宽 1080，单张高不超过 8192。PC 优先正文块边界，Android 按 PDF 页面边界逐页栅格化和分组合并；逐张编码，位图工作集有上限。
- PC 文件直接保存到系统下载目录的 `Joi`，安全任务标题、时间和随机后缀构成文件名；多图编号。隐藏暂存目录通过排他硬链接发布，已完成清单用于恢复，失败只移除本任务拥有的文件，不覆盖用户文件。
- SQLite 迁移 057 保存私有正文快照和导出状态，创建任务与 `result.export` outbox 同事务；稳定幂等键复用任务。主进程重新读取正文并校验 SHA-256，变更时提示重新打开全文。接口不接受任意 HTML、URL、保存路径，不返回绝对路径。
- Electron 使用隔离 session、沙箱、禁用 Node、受控自定义协议、网络拒绝和 HTML 跳过。PDF 使用 printToPDF；PNG 使用 Chromium 文档坐标捕获，避免显示器限制截断隐藏窗口。
- Android 10+ 写 `MediaStore.Downloads` 的 `Download/Joi`，全部写完才发布。旧版通过系统目录选择器持久授权，在所选目录创建 Joi。保存集合使用本地任务 ID，待发布 URI 有恢复日志；不申请广泛存储权限。

## 2026-10-15 Android 导出可靠性增量（AC-57）

- PDF 排版与 PNG 拼图/编码在每次导出的独立 Dart worker 内完成；字体资产与 printing 平台回调保留在主 isolate。字体、正文和位图不进入日志。
- PNG 正确读取 RGBA 视图的起始偏移和长度，透明区域合成白底；缩放前校验目标高度。根据排版产生的页数，每次只请求一页，收到并处理完成后再请求下一页。分图保持 1080px 宽与不超过 8192px 高。
- Android 离线增加 Noto Sans Symbols 2 与 Noto Emoji 常规字体及各自 OFL 许可。常见符号与 Emoji 以单色呈现，无法绘制的字符/组合显示明确的 Unicode 码位；原始 Markdown 复制保持不变。
- PDF ToUnicode 映射使用 UTF-16BE，补充平面字符使用代理对，映射按每组最多 100 条输出。嵌套列表、硬换行、表格图片占位与链接保留；长表格按有界单元格分段，超过八列的表格按行转为纵向展示。
- Android 保存后回读文件并校验长度及 SHA-256，所有文件通过后才发布。旧版 SAF 需同时持有读取和写入授权。失败清理本次未发布 URI，界面区分排版、图片转换、保存失败与用户取消。
- 回归包含实际平台消息编码产生的非零偏移像素、分图全像素参考比较、中文多页正文、150 个不同汉字的 CMap 分组、符号/Emoji、长代码/表格、失败清理与重试。Kotlin 本地测试覆盖成功复制、截断与同长度篡改。
- PDF 内容验证命令：`python scripts/verify-result-export.py tmp/export-validation/android-result.pdf --complex tmp/export-validation/android-complex-result.pdf`。首尾页与复杂样例中间页均需实际渲染检查。
- 真机待验继续按本文设备清单执行；没有连接设备时不得将 MediaStore/SAF、第三方查看器和设备峰值内存标为通过。

本轮验证：Flutter analyze 无问题、85 项 Flutter 测试与 3 项 Kotlin 完整性测试通过；PDF 样例分别为 5 / 8 页，正文、链接、Unicode 与边界检查及首/中/尾页视觉检查通过，分段 PNG 全像素参考比较通过。ARM64 APK 构建和 v2 调试签名验证通过，17 份 Dart 源码、15 个原生库、8 个品牌/字体/许可资产与构建输入一致；包内 DEX 与 R8 输出一致。
