# 目标续聊与深层路线图

**状态 · 已确认**

## 问题

目标长期续聊后，路线图可能一直显示第 32 层。路径规划和雾区晋升的工具拒绝更大的层号，自动补建的 Work 路径也被压到第 32 层。多轮工作因此堆在同一层，最近进展难以与历史记录区分。

路线图已经分页。详情展开后，当前实现会为已加载的折叠历史层创建路径卡片。即使折叠层只显示标题，长期目标累积的数百或上千层也会让路线图难以浏览。

## 目标

续聊仍沿用原目标、已有路径和证据。新需求需要执行时，Joi 可以续写路线图。桌面路线图最多展示每个目标最近 100 个有路径的层，较早的路径和证据仍可供 Joi 核查。自动续跑继续由现有的目标额度和执行门禁控制。

## 用户故事

1. 作为长期推进同一目标的用户，我希望已完成第 32 层后可以规划第 33 层，以便区分新一轮工作和历史任务。
2. 作为在原目标补充要求的用户，我希望 Joi 先读取当前层和相关证据，以便只安排这次需要的工作。
3. 作为只追问已有结论的用户，我希望直接获得回答，以便路线图继续反映实际执行。
4. 作为查看长期目标的用户，我希望路线图只保留最近 100 层的展示，先看到最新层，再按需展开范围内的历史层，以便快速定位路径。
5. 作为处理待确认事项的用户，我希望自动续跑在额度用完后仍交由我决定，以便继续完善或保留当前结果。
6. 作为升级后续聊旧目标的用户，我希望 Joi 仍能查到原路径编号、状态、决策和 Work 引用，以便核对已有结论。

## 续聊与分层

- Joi 在需要规划路径的续聊中先读取当前层号和最新一页路径。最新层仍有待处理路径时，优先整理同层工作。当前层结清且新请求需要执行时，从已保存层号接出下一层。可直接回答的续聊沿用原路线图。
- 路径创建、自动补建和雾区晋升使用一致的层号规则。层号使用可精确表示的正整数。同一轮的一组 Work 共用一层，分批补建沿用已分配的层号和稳定路径身份。
- 旧目标以最近已保存的路径层作为接续依据。旧评审已体现在已有层里，后续分层只计入锚点后的新进展。若旧目标最后保存在第 32 层，且一轮新工作满足推进条件，下一层就是第 33 层。
- 雾区晋升可以指定层号。省略层号时，放入最新仍开放的层。最新层已结清时放到下一层。
- 路线图沿用现有路径引用。历史路径、Work 与决策全部留存，Joi 可按需查询，包括已退出桌面展示范围的层。

## 自动续跑额度

- 层号用于路线图排序和规划定位。目标持久记录已使用的自动续跑轮数。每个成功入队的自动补充评审占用一轮，重试复用同一个评审身份。升级时沿用存量目标原有的剩余额度，额度耗尽时继续提供「继续完善」和「保留当前结果」。
- 用户显式续聊可在现有执行门禁下规划本次需求。续聊保留原目标的自动续跑额度。「继续完善」沿用现有的授权方式增加额度。

## 深层路线图优化

- 规划工具直接返回当前层号、当前层是否还有开放路径，以及最多 8 条的分页结果。Joi 按层或游标读取需要的历史。路线图排序或当前层的开放状态变化后，旧游标要求重新读取首页。
- 桌面路线图按层号从高到低保留最近 100 个实际有路径的层，层号有跳号时按实际层数计。新增一层超出上限时，最旧层永久退出该目标的桌面路线图。刷新、重新打开和翻页都遵循同一展示范围，引用也无法重新展开已退出的层。
- 桌面路径总数、「已加载 / 共计」和分页都按可见层内的路径计算。
- 桌面沿用默认每页 50 条和「已加载 / 共计」提示。页面对已加载路径一次分组，默认展开最新层。折叠层只显示标题，展开时加载该层已获取的卡片内容。
- 可见范围内沿用已有的路径选择、展开状态、分页、失败重试和版本一致性。

## 验收

1. 用旧第 32 层和多轮历史评审构造隔离目标，分别验证显式续聊和新评审产生的 Work 都接到第 33 层。存量路径编号、状态和引用可正常读取。
2. 验证同轮 Work 分批补建时共用层号，重复同步保持路径数量和身份。验证普通问答保留原层号。
3. 验证第 33 层以后可手动规划和晋升雾区。无效层号、跨目标 Work 和额度耗尽继续走现有校验与用户决策流程。
4. 用第 96 层、865 条路径的合成路线图验证当前层显示、默认展开、历史按需展开和分页。折叠层的路径卡片从界面移除，重新展开可查看。
5. 用 1,050 个有路径的层验证桌面只展示第 951 至 1050 层。新增第 1051 层后，第 951 层永久退出，刷新、重开、翻页和旧路径引用均无法恢复其显示。验证层号跳号时仍按实际层数计，桌面路径计数和分页匹配展示范围，Joi 仍能读取已退出层的路径和证据。
6. 用路线图读取、继续目标、评审和前端测试验证首屏有界、同一版本内可分页，以及排序变化后拒绝旧游标。
