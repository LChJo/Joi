# 任务二级页与 C2 首页视觉复核

设计判断：这是沿用 joi 绿灰体系的紧凑任务阅读界面。保留现有纸色、森林绿、圆角和图标家族，把标题层级、按钮排布和交互反馈调回同一密度；不引入新设计系统或装饰动效。对应 AC-37、AC-40、AC-48。

## 审计发现

- 用户截图来自 `GoalResultView` 的结果抽屉。它与任务详情共用 `.joi-goal-detail-header`，操作区却使用通用 `.row-actions`，没有禁止收缩和按钮标签换行。长中文标题与按钮竞争宽度时，“查看详情”“关闭”退化为逐字竖排。
- `.joi-goal-detail-title h1` 仅明确字号，仍继承全局大标题的紧行高、字距与字重。任务详情的 `GoalTitle` 限两行，结果抽屉的普通 `h1` 没有限制，两个二级页面密度不一致。
- C2 原稿 `docs/design/joi-home-c-compact.html#c2` 的任务标题只通过 `.task-title:hover { color: var(--accent); }` 反馈。卡片面板不填充、不位移、不更改边框。生产页继承 `.joi-goal-open:hover` 的森林绿 5% 底色，未按 C2 覆盖。
- 首页任务圆形目前统一呈现 `StackIcon`。用户最新要求改为项目名缩写，此要求覆盖原稿图标方案。`JoiGoalCardDto.workbench` 和 `WorkbenchDto` 目前只有工作台 `name`，真正的项目名 `projectLabel` 位于 `WorkbenchDetailDto`；实现时应明确取值来源。

## 最小调整规格

| 元素 | 规格 |
| --- | --- |
| 二级页标题 | 19px、600 字重、1.5 行高、字距 -.015em，最多两行；标题容器 `min-width: 0`，长英文可断行。 |
| 工作台眉题 | 12px，森林绿，1.5 行高；单行省略，避免挤压标题和操作区。 |
| 状态和时间 | 12px，1.45 行高，自然换行，不与标题争夺主层级。 |
| 头部操作 | 使用抽屉头部的直接子元素作用域约束操作区；容器 `flex: 0 0 auto`，按钮 `flex-shrink: 0`、`white-space: nowrap`。 |
| 文本操作按钮 | 最小高度 36px、横向内边距 12px、13px 字号、1.4 行高；“查看详情”和“关闭”始终横排。 |
| 窄屏头部 | 600px 以下，标题整行，操作在下一行右对齐；允许操作组换行，不允许按钮内部换行。保持 16px 左右内边距。 |
| C2 标题悬停 | 仅标题由 `var(--ink)` 变为 `var(--forest)`；原稿浅色森林绿为 `#285f48`。开启按钮底色保持透明，结果摘要保留自己的静态底色。 |
| C2 键盘焦点 | 开启按钮聚焦时标题同样变森林绿，并保留清晰 `focus-visible` 轮廓；不可只靠颜色表示焦点。 |
| 结果正文 | 14px，1.7 行高；正文 Markdown 的局部标题按正文比例排列，不继承页面大标题。 |

详情标题原有悬停全文、点击固定、右键复制和键盘菜单继续保留。结果页限制标题行数后，完整任务详情入口必须始终可见；不要把首页截断文本当作原始全文。

## 项目名圆形标识

保留 C2 40px 圆形的纸色底、细边框、森林绿文字与内圈。使用短文本直接区分项目，不从任务正文推断类别。

- 数据优先采用真实 `projectLabel`，缺失时回退工作台 `name`。首页可通过现有 home-feed 安全 DTO 投影补充该字段；避免为每张卡单独读取详情。
- 纯英文名显示前 4 个字母或数字，忽略空格与分隔符；中文名显示前 2 个汉字。混合名称的规则应作为固定展示契约实现并测试，建议含汉字时取前 2 个汉字，否则取前 4 个字母或数字。
- 示例：`ai mana front debug` 显示 `aima`，`digital-life` 显示 `digi`，`燃脂打卡` 显示 `燃脂`，`AI助手` 显示 `助手`。保留原文大小写，不生成拼音或语义缩写。
- 四个拉丁字符使用本地 `Consolas`、`Cascadia Mono`、`monospace` 字体栈，10px、600 字重；两个汉字使用既有中文字体，13px、600 字重。行高 1、字距 0、单行居中。窄屏 36px 圆形仍采用这组字号。
- 已归档的 32px 圆形使用中文 12px，四个拉丁字符维持等宽字体 10px。全部圆形禁止文字换行，宽字符 `WWWW` 也应保持单行且不越界。
- 空白项目名回退工作台名，再缺失时显示 `joi`。圆形设 `aria-hidden`，邻近完整工作台名继续承担可访问名称。

## 验收建议

1. 使用合成长中文标题、无空格英文标题和长工作台名，验证结果页、任务详情在 480px、768px、1280px 下标题最多两行，按钮文字保持横排，无头部横向溢出。
2. 对结果页“查看详情”“关闭”检查计算样式与实际边界；按钮不被标题推离视口，切入详情、退出结果页仍可操作。
3. 首页对比鼠标进入前后的计算底色：开启按钮保持透明、卡片底色不变，标题变为森林绿。鼠标离开恢复，Tab 聚焦保留轮廓，Enter 仍打开详情。
4. 圆形标识至少覆盖英文、中文、中英混合、空白和已归档任务；在 40px 与 36px 圆内保持单行、居中、无裁切。
5. 使用隔离 userData 与合成 DTO 生成真实窗口截图，再复核字号、标题行高、操作行与任务圆形。该文档是设计建议，不代表实现或测试已经通过。

## 实现审查

生产差异只读审查确认：两个抽屉的标题明确字号、行高和字重，结果页标题限两行；结果页操作保留现有 DOM，以抽屉头部直接子元素作用域禁止收缩、禁止标签换行。600px 以下标题与操作分行。C2 开启区域透明，标题在悬停与键盘焦点时变森林绿。结果正文为 14px / 1.7。

首页 DTO 增加可选 `workbench.projectLabel`，与任务投影同次查询读取并通过现有安全文本处理。圆形优先项目名、回退工作台名，按含汉字取前两字、其余取前四个字母或数字的规则展示，保留原文大小写。

已归档 32px 圆形明确采用中文 12px、拉丁字符等宽字体 10px，所有圆形标识禁止换行，避免既有归档字号覆盖普通缩写字号。拉丁字符采用本地等宽字体，在普通与已归档卡片保持一致字号和可辨识性。

## 真实窗口视觉复核

已查看生产构建生成的 `test-results/e2e-result-header-1280-light.png`、`e2e-result-header-480-dark.png`、`e2e-task-header-480-light.png` 与 `e2e-home-c2-1280-light.png`。两级页面标题不再撑高为大段正文，结果页“查看详情”“关闭”横排，窄屏操作在标题后另起一行并右对齐。浅色与深色下标题、状态和正文对比清楚，正文有足够可见阅读区域。首页中文、英文缩写居中，卡片和输入器密度保持 C2 的阅读节奏。以上界面通过视觉复核，没有阻塞问题。

再次查看更新后的 `test-results/e2e-goal-archived-card.png`，已归档 32px 圆形显示 `WWWW`，四字符保持单行、居中且未越界；紧凑卡片的工作台名、目标、归档时间及右侧状态操作排列清楚。四字符缩写的视觉证据已补齐。结合生产差异与上述真实窗口截图，本次视觉审查通过，没有影响用户请求的遗留问题；自动化验证结果由实现者记录。
