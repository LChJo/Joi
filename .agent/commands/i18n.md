# 语言维护

从仓库根目录执行；源目录是 `resources/locales/`，生成的 TypeScript、Flutter ARB 和消息适配器不手改。

```powershell
npm run i18n -- help
npm run i18n -- stats
npm run i18n -- stats --json
npm run i18n -- locale add fr Français
npm run i18n -- sync
# 编辑 resources/locales/fr 中的翻译，完成后再启用
npm run i18n -- locale enable fr
npm run i18n -- locale remove fr
npm run i18n -- key add common.example "Example {name}"
# 编辑英文说明和其他语言翻译后生成
npm run i18n -- generate
npm run i18n:check
# 先移除代码引用，再删除文案
npm run i18n -- key remove common.example
```

新增语言默认未启用，启用语言必须拥有有效且完整的翻译。英文基准不可删除。删除语言会移除其生成资源；旧偏好在运行时回到跟随系统。

Flutter 本地化类由 SDK 生成，不纳入版本控制：

```powershell
Set-Location apps/joi_mobile
flutter gen-l10n
flutter analyze
flutter test
```

维护完成后执行仓库全部固定门禁和架构边界检查。具体含义及限制见 `docs/20-internationalization.md`。
