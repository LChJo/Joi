- 主页保留 960px 单栏目标流；任务有独立底色，8px 间距、12px 纵向内边距与柔和圆角。页面标题 26px、目标 15px、工作台和元信息 12px。

- 目标流独立滚动；菜单定位到视口并避让边缘，外部滚动或缩放时关闭，Escape 回到触发器。归档、澄清、状态、计数、正文、附件和分发仍使用原有服务契约。
