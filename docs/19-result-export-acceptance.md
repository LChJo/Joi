# PC 与 Android 最终结果导出（AC-57 增量）

## 内容与交互

- 阅读快照唯一正文为 `completionSummary`，复制保留原始 Markdown，包括末尾空白；不拼入提问、标题、状态、日志或附件。
- PC 全文弹层固定打开时的正文；Android 从首页结果预览和详情“最终结果 · 查看全文”进入独立页面，调用既有 `goal.get` 分片重组。完整读取前、读取失败或空正文不能导出；已加载快照离线可用。
- 右下角常驻导出图标向上展开复制/PDF/PNG。空白和 Escape/返回优先关闭菜单。底部保留阅读空间，处理中禁用重复操作，失败不显示保存成功。
- 浏览器会话仅提供复制；文件导出、打开和目录定位需要 desktop session，写操作继续校验 Origin/CSRF。
- PC 导出反馈使用紧凑灰绿状态卡：图标与文件数量为主信息，下载 / Joi 为次级位置，同一卡片底部集中放置“打开”和“打开目录”；复制、处理中和错误提示沿用同一容器，屏幕阅读器可读取状态。

## 格式与存储

- 两端使用同一份离线 Noto Sans SC 常规字体和 OFL 许可证。PDF 为 A4 白底、可选文本、分页正文、HTTP(S) 链接；表格和长代码/链接可换行。图片保持占位，不请求外部图片。
- PNG 宽 1080，单张高不超过 8192。PC 优先正文块边界，Android 按 PDF 页面边界逐页栅格化和分组合并；逐张编码，位图工作集有上限。
- PC 文件直接保存到系统下载目录的 `Joi`，安全任务标题、时间和随机后缀构成文件名；多图编号。隐藏暂存目录通过排他硬链接发布，已完成清单用于恢复，失败只移除本任务拥有的文件，不覆盖用户文件。
- SQLite 迁移 057 保存私有正文快照和导出状态，创建任务与 `result.export` outbox 同事务；稳定幂等键复用任务。主进程重新读取正文并校验 SHA-256，变更时提示重新打开全文。接口不接受任意 HTML、URL、保存路径，不返回绝对路径。
- Electron 使用隔离 session、沙箱、禁用 Node、受控自定义协议、网络拒绝和 HTML 跳过。PDF 使用 printToPDF；PNG 使用 Chromium 文档坐标捕获，避免显示器限制截断隐藏窗口。
- Android 10+ 写 `MediaStore.Downloads` 的 `Download/Joi`，全部写完才发布。旧版通过系统目录选择器持久授权，在所选目录创建 Joi。保存集合使用本地任务 ID，待发布 URI 有恢复日志；不申请广泛存储权限。
