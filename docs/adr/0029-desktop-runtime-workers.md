# ADR 0029：本地运行时与窗口线程隔离

状态：接受。验收：AC-PERF-01。joi 长期保持每台电脑独立运行的个人应用，SQLite 仍为本机事实存储。

历史会话不代表可调度任务。只按非终态派发、存活实例及非终态 run 构建 Agent；已结束的会话仍可查看。内存中的执行及孤儿收尾未完成时，Agent 必须留在唯一 Actor 树中，直至终态提交与容量释放完成。

Electron 窗口主线程只负责窗口、托盘和原生能力。一个运行时 Worker 承载应用服务、HTTP、Actor 根循环和唯一可写 SQLite 连接。现有同步事务在同一线程内完整执行，Work/outbox、版本检查、幂等标识和执行代次的原子边界保持完整。Worker 属于同一桌面进程；独立服务进程和物化汇总暂不引入。

首页读取使用独立只读 Worker。它在迁移完成后打开只读连接，启用 query_only，使用 BEGIN/COMMIT 建立 WAL 读快照；不执行 BEGIN IMMEDIATE。一次完整投影使用同一快照，后续读取可见已提交状态。其余业务查询仍在运行时 Worker 中；后续根据测量决定是否扩展独立读仓储。

Migration 074 提供目标来源、最新回合、Work 对应实例/run 和可见会话的索引。查询从目标关联的来源/Work 开始，以 CROSS JOIN 固定必要的连接顺序；最新回合包含派生输入并保留时间/ID 排序，Agent 数按稳定 agent_id 去重。历史增长不得使每张目标卡扫描全部回合或会话。

线程之间只在私有 MessagePort 上传输命名命令和数据；不传递 SQL 或可执行回调。窗口的业务 API 继续使用 /api/v1。凭据加解密、目录选择、图片转换、产物打开和 PDF/PNG 渲染通过窄原生能力请求主线程；导出状态仍由写 Worker 持久化。错误通道只保留安全原因码，不包含 SQL、路径或私密正文。未完成请求上限为 256，线程退出拒绝等待者；运行时 Worker 异常退出使桌面进程退出，保留启动标记供下次恢复。

正常退出先停止根计时器和入口，等待在途根遍历，完成原有 outbox 收尾，再关闭完整性检查、只读 Worker 和写连接，最后清理启动标记。只读 Worker 在未提交写事务期间仍须读取上一份已提交快照；退出前已提交的请求须得到响应。

代价是两个 Worker 的固定内存开销和少量消息传输；换取窗口线程不执行数据库扫描和后台遍历。该隔离不保证所有 HTTP 查询永远即时完成，运行时 Worker 中的大查询仍需按测量优化。
