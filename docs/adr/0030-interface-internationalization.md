# ADR 0030：界面语言与任务内容分离

- 状态：已接受
- 日期：2026-10-15
- 验收：AC-I18N-01 至 AC-I18N-06

## 决策

`resources/locales/` 是唯一翻译源。英文是不可删除的源语言及缺词回退；简体中文与英文默认启用。语言注册表驱动选择器、TypeScript 类型、Flutter 语言注册与生成资源，新增语言不要求改页面分支。

采用 FormatJS ICU 与 Flutter gen-l10n 的公共子集：命名插值、cardinal plural 和 select。不使用内嵌 HTML、#、offset 或两端不一致的日期数字骨架；日期数字使用各端统一的区域格式化入口。

生成的 TypeScript、Flutter ARB 和消息枚举适配器纳入版本控制，Flutter SDK 生成的本地化实现不纳入版本控制。区域语言同时生成 Flutter 所需的基础语言回退。CI 和生产构建拒绝资源漂移、参数错误、缺译及未知代码引用。

## 偏好与实时性

偏好为 `system` 或注册且启用的 BCP 47 语言代码。默认跟随系统，中文匹配 `zh-CN`，不支持的语言回退 `en`。已移除语言的偏好按 `system` 解析。

桌面偏好经现有 HTTP 设置服务串行写入 `settings.json`，Worker 通过内部原生能力更新托盘。只读启动信息提供偏好与系统语言；preload 不增加业务写入口。语言单字段更新不触发 LAN、技能、开机启动或模型调用。浏览器使用同源本地存储，手机使用独立的原子替换偏好文件，不修改主机语言。

React 通过可订阅的语言状态更新文案，Flutter 更新 `MaterialApp.locale`。通知保存消息标识与参数，渲染时格式化；公开 UI 状态、连接对象及输入框保持稳定，不用刷新或换 key 实现切换。恢复控制台只依赖随包文案，桌面语言写入沿用恢复模式的同源限制。

## 内容与兼容性

任务正文、提示词、人格、模型输出、已有名称、路径及外部 Skill 内容不参与翻译。只在明确属于产品界面的边界格式化文案；真实文件夹名即使等于某条文案，也保持原值。预设说明可以翻译，安装与执行仍消费原有业务定义。

HTTP/远程错误码与权限保持不变。客户端优先按已知原因码显示文案；只对目录中逐字匹配的已批准旧提示提供兼容映射。未知后台文字显示固定安全提示，不直接显示异常原文。业务流程不按显示文本判断。
