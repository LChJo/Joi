# ADR 0021：本地 Token 用量与任务统计

- 状态：Accepted
- 日期：2026-09-22

新增一级统计页面，仅统计 Token，不估算费用。采集 joi 发起的 Pi、原生 Codex/Claude 与 A2A 执行；没有供应商用量的记录明确保留未知。不解析历史私有会话补数，不新增外部遥测或真实模型调用。

输入含缓存读取/写入，输出含推理，细分不能再次加入总量。供应商累计快照按调用内稳定标识替换，实际重新执行另开记录。统计持久化故障不得改变任务结果，查询必须暴露采集异常。数值记录不包含正文、密钥、端点或路径。

## 验收

- AC-STATS-01：三种 SDK 用量归一化、流式完成、失败/中断、累计去重；A2A 明确未知。
- AC-STATS-02：SQLite 数值账本、版本化来源、归属隔离、故障隔离、启动恢复；历史不补算。
- AC-STATS-03：366 天以内时区查询、日期与星期小时聚合、排名与分组对账、Top 10、目标去重、缺失覆盖率。
- AC-STATS-04：认证 HTTP /api/v1/statistics 与安全共享 DTO，Renderer 不访问数据库或 Node。
- AC-STATS-05：设置下方统计导航、联动筛选、双热力图、数据表替代、目标跳转、15 秒可见刷新、加载/空/未知/错误状态；768/960/1440px 与浅深主题视觉复核。
- AC-STATS-06：类型、lint、完整测试、90% 覆盖门槛、Electron E2E、生产构建、包验证与架构边界全部通过。
