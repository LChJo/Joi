# Joi Android

Joi 的受限原生远程控制端。App 通过 `joi://pair` 二维码绑定桌面 Joi，使用 iroh 自动选择局域网直连或远程中继。

首页支持选择已有工作台发送（或由 joi 判断）、阅读完整展示正文与保存的结论、查看目标内搭档记录、回答澄清、继续已结束对话、取消和移除允许移除的卡片。详情用原生 Markdown 展示，产物只显示信息，不开放文件或管理配置。

新版桌面握手声明 `home.v2` 后启用完整操作；旧桌面保留任务列表与发送，并提示升级。需要同时更新桌面和 APK。发送失败保留草稿，同一内容与工作台重试复用幂等键；收到成功回执后，刷新失败不会把发送判为失败。

从仓库根目录构建：

```powershell
npm run build:mobile:android
```

release APK 输出到 `release-joi-mobile/joi-android-0.1.0-arm64.apk`。当前 release 变体使用调试签名，适合手动侧载验收；应用商店发布前必须替换为正式签名。

品牌采用与桌面一致的 C「深绿版画」Joi 肖像和艺术字标，应用于启动图标、配对页与首页。Android 8 及以上使用自适应图标，兼容图标提供五套密度。

构建入口会先同步桌面图标和移动品牌素材。生成器 `scripts/render-mobile-brand.cjs` 从桌面主图、侧栏头像与 SVG 字标派生 Android / Flutter 资产，兼容图标采用无嵌入色彩配置的位图编码，保持安卓资源压缩后的显示颜色。

预览与 APK 校验见 [品牌交付记录](../../docs/design/joi-android-c-package-verification.md)。

任务卡与详情区分正在执行与资源排队，显示“等待执行容量”“等待工作区可读”“等待写入”；搭档记录显示分析与写入阶段，前台刷新后及时反映阶段变化。旧主机未提供这些字段时保留普通进度显示；这些等待不要求用户回答，也不代表任务完成。
