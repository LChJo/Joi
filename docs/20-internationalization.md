# 全客户端国际化验收

界面语言独立于任务、人格和模型回复语言。语言资源随应用离线发布。

| 验收 | 行为 |
| --- | --- |
| AC-I18N-01 | 唯一语言源目录生成类型安全 TypeScript 与 Flutter ARB；启用语言完整，CLI 支持维护与覆盖率统计。 |
| AC-I18N-02 | 默认跟随系统，中文系统使用 zh-CN，其余使用 en；显式选择优先，失效偏好回到系统。 |
| AC-I18N-03 | 手动切换立即更新界面、提示、无障碍标签和日期数字，不刷新、不丢失草稿、不重建任务或连接。 |
| AC-I18N-04 | 桌面、浏览器和手机偏好独立持久化；桌面更新托盘，语言修改不触发 LAN 或其他设置副作用。 |
| AC-I18N-05 | 当前所有产品界面支持中英文；用户内容、历史数据和任务提示词保持原文。 |
| AC-I18N-06 | 旧配置和未知错误安全回退；代码和原因码不变，翻译不改变授权、幂等和调度。 |

## 维护

源目录为 resources/locales；英文是基准，翻译使用 ICU 插值、plural、select。日期数字由各端格式化入口处理。
生成资源不手改。使用 npm run i18n -- help 查看维护命令；stats --json 输出机器可读报告，check 验证启用语言完整性和生成资源一致性。

具体命令见[语言维护索引](../.agent/commands/i18n.md)。新增语言默认禁用，补齐翻译后启用；新增 key 自动同步空翻译并推导插值参数类型。空值或英文回退不会被算作已翻译。删除仍被 TypeScript、原生菜单或 Flutter 引用的 key 会拒绝；删除语言同时清理区域回退 ARB。

## 接口与持久化

- `SystemSettingsDto` 与更新输入增加可选 `uiLocale`，值为 `system` 或启用语言。旧配置默认 `system`；仅桌面会话可以修改主机偏好。
- 桌面只读启动信息增加可选 `uiLocale` 与 `systemLanguages`。保存仍走 HTTP，Worker 通过内部 `setUiLocale` 能力刷新托盘。
- 浏览器偏好为 `localStorage["joi.uiLocale"]`，同源标签页同步；手机为应用支持目录中的独立 `ui-preferences.json`，串行原子替换。测试使用临时目录，不读取真实用户设置。
- 桌面恢复模式提供受现有同源约束保护的 `/api/v1/recovery/ui-locale`；浏览器恢复页只保存自己的本地偏好。该入口不依赖 SQLite，不扩张恢复操作权限。
- 文案缺失按英文回退；通知按 key 和参数重新渲染。已批准旧提示仅按目录逐字匹配，其他后台异常不直接展示。任务提示词、人格、路径、姓名和模型输出保持原文。
